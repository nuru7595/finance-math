Chapter 3: Time Value of Money
📌 Notes
  • যদি বছরে একাধিকবার (m বার) compounding হয় — যেমন semi-annual (m=2), quarterly (m=4), bi-monthly (m=6), monthly (m=12) — তাহলে যেকোনো ফর্মুলায় i এর জায়গায় i/m এবং n এর জায়গায় nm বসাতে হবে।
  • যদি annuity due হয় — তাহলে সংশ্লিষ্ট Ordinary Annuity ফর্মুলার সাথে অতিরিক্ত (1 + i) গুণ করতে হবে।
Simple Interest — Future Value
FV = P + P·N·i
কখন ব্যবহার হবে: যখন সরল সুদে (Simple Interest, compounding ছাড়া) কোনো Principal (P)-এর ভবিষ্যৎ মূল্য (Future Value) বের করতে হবে — N বছরের জন্য, বার্ষিক সুদের হার i তে।
Compound Interest — Future Value (Lump Sum)
FV = PV ( 1 + i )n
কখন ব্যবহার হবে: যখন একটি একক Present Value (PV)-কে চক্রবৃদ্ধি সুদে (Compound Interest) n বছর পর কত হবে তা বের করতে হবে।
📝 m (compounding frequency) এবং due সংক্রান্ত নোট উপরে দেখুন।
Future Value of an Annuity (Ordinary)
FVA = Ai { ( 1 + i )n − 1 }
কখন ব্যবহার হবে: যখন প্রতি বছর/period সমান পরিমাণ টাকা (Annuity, A) জমা দেওয়া হয় এবং ভবিষ্যতে তার মোট মূল্য (Future Value) বের করতে হবে।
📝 Annuity due হলে শেষে (1 + i) গুণ করতে হবে।
Present Value (Lump Sum)
PV = FV( 1 + i )n
কখন ব্যবহার হবে: যখন ভবিষ্যতের একটি নির্দিষ্ট পরিমাণ টাকার (Future Value) বর্তমান মূল্য (Present Value) বের করতে হবে — অর্থাৎ discounting করতে হবে।
Present Value of an Annuity (Ordinary)
PVA = Ai { 1 − 1( 1 + i )n }
কখন ব্যবহার হবে: যখন প্রতি বছর/period সমান পরিমাণ টাকা (Annuity, A) ভবিষ্যতে পাওয়া যাবে, এবং তার বর্তমান মূল্য (Present Value) বের করতে হবে।
📝 Annuity due হলে শেষে (1 + i) গুণ করতে হবে।

Portfolio Expected Return E(Rp)
E(Rp) = R1·W1 + R2·W2
📝 W₁ + W₂ = 1 (সবগুলো Weight-এর যোগফল সবসময় ১০০% বা ১ হবে)।
Portfolio Standard Deviation without Correlation
√σ12W12 + σ22W22
Portfolio Standard Deviation with Correlation
√σ12W12 + σ22W22 + 2·σ1·σ2·W1·W2·Corr1,2
📝 Correlation-এর বদলে সরাসরি Covariance দেওয়া থাকলে, 2·σ1·σ2·W1·W2·Corr1,2 এর জায়গায় 2·W1·W2·Cov1,2 বসানো যায়।
Portfolio Beta
βp = β1W1 + β2W2 + β3W3
কখন ব্যবহার হবে: একাধিক সিকিউরিটি/Asset নিয়ে গঠিত Portfolio-র Systematic Risk (Market Risk) measure করতে — প্রতিটা Asset-এর Beta-কে তার Weight দিয়ে গুণ করে যোগ করতে হয়।
